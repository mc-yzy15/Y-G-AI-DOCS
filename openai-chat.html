Chat Completions

OpenAI 兼容的聊天补全接口，兼容现有 OpenAI SDK 与大量第三方客户端，是接入最方便的方式。

接口信息

请求方式POST
请求路径https://ai.yzy15.dpdns.org/v1/chat/completions
鉴权Authorization: Bearer sk-...
Content-Typeapplication/json

请求示例

curl
curl https://ai.yzy15.dpdns.org/v1/chat/completions \
  -H "Authorization: Bearer sk-YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-4o",
    "messages": [
      {"role": "system", "content": "你是一位乐于助人的助手。"},
      {"role": "user", "content": "请用三句话介绍瀛光 AI"}
    ],
    "temperature": 0.7,
    "max_tokens": 1024,
    "stream": false
  }'

核心请求字段

字段类型说明
modelstring必填，模型 ID，见「模型列表与选择」。
messagesarray必填，对话消息列表，支持 system / user / assistant 角色。
temperaturenumber采样温度，0–2，默认 1。
max_tokensinteger最大生成 token 数。
streamboolean是否流式返回，默认 false。
top_pnumber核采样，0–1，可选。

流式输出

设置 "stream": true 后，服务端以 SSE 逐块返回 data: {...}，每块包含增量 choices[].delta.content，结尾发送 data: [DONE]。

SSE 输出示例
data: {"choices":[{"delta":{"role":"assistant"},"index":0}]}

data: {"choices":[{"delta":{"content":"你好"},"index":0}]}

data: {"choices":[{"delta":{"content":"！"},"index":0}]}

data: [DONE]

响应结构

JSON 响应示例
{
  "id": "chatcmpl-xxx",
  "object": "chat.completion",
  "created": 1755000000,
  "model": "gpt-4o",
  "choices": [
    {
      "index": 0,
      "message": {
        "role": "assistant",
        "content": "瀛光 AI 是……"
      },
      "finish_reason": "stop"
    }
  ],
  "usage": {
    "prompt_tokens": 42,
    "completion_tokens": 120,
    "total_tokens": 162
  }
}

使用 OpenAI SDK

Python + openai
from openai import OpenAI

client = OpenAI(
    api_key="sk-YOUR_API_KEY",
    base_url="https://ai.yzy15.dpdns.org/v1",
)

resp = client.chat.completions.create(
    model="gpt-4o",
    messages=[{"role": "user", "content": "你好"}],
    stream=True,
)
for chunk in resp:
    if chunk.choices and chunk.choices[0].delta.content:
        print(chunk.choices[0].delta.content, end="")
模型 ID 与平台实际提供范围有关。若返回 model not found 或 400 错误，请到控制台「模型广场」核对可用模型 ID。
