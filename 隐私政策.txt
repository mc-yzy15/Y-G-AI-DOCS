# 瀛光AI隐私政策
**生效日期**：2026年6月1日
**运营主体**：北京仙盛科技有限公司
**官方平台**：瀛光AI（官网：https://ai.yzy15.dpdns.org/）

本隐私政策适用于瀛光AI平台及其相关服务。平台深知个人信息保护的重要性，除遵守法律法规外，亦将根据业务运行需要，按照合法、正当、必要和最小化原则处理用户信息。本政策用于说明平台在提供API转发、账号管理、计费结算、客服支持、安全风控及相关运营过程中，如何收集、使用、保存、共享、保护和处理用户信息，以及用户可依法享有的权利。

如用户使用平台服务，即表示已阅读并理解本隐私政策的内容。对于法律规定需要另行取得同意或提供单独告知的事项，平台将依法另行处理。

## 一、适用范围
本政策适用于用户在使用平台账号、API 服务、第三方登录、支付、客服、推送配置、安全验证及其他相关功能时，平台对个人信息和服务数据的处理行为。

本政策不适用于平台外部第三方独立提供的服务。用户通过平台跳转、接入或调用第三方服务时，应同时阅读第三方的隐私政策或服务条款。

## 二、个人信息处理的基本说明
平台主要提供 AI API 转发与聚合服务。平台本身不保存用户提交的请求正文，但为完成用户发起的调用，平台会将请求转发至用户选择的境内或境外上游模型服务商。上游服务商可能根据其自身规则保存、审查、分析、用于改进服务，或在其政策允许的范围内用于训练；平台无法控制上游的具体处理行为。

因此，平台建议用户不要通过请求正文或相关附件提交身份证件、密码、验证码、支付凭证、商业秘密、未授权的个人信息或其他不必要的敏感信息。

## 三、平台收集、使用和保存的信息
平台仅收集为实现服务所必需的信息，主要包括以下几类：

### 1. 账号与安全信息
平台在用户注册、登录、身份验证和账户安全管理过程中，可能收集和保存以下信息：
- 邮箱地址；
- 账号昵称或登录标识；
- 密码的加密校验信息；
- API Key 与其关联的用户身份信息；
- 账户状态、权限信息、封禁或限制记录；
- 安全审计日志、登录日志、异常访问记录。

上述信息用于账号创建、身份识别、权限控制、安全审计、故障排查及风控管理。

### 2. 第三方登录与 OAuth 记录
平台支持 GitHub、Telegram 等第三方登录。用户授权后，平台可能接收第三方返回的必要账号标识、头像、昵称、OpenID、UnionID、授权令牌相关必要记录，以及 OAuth 回调过程中产生的必要日志。

平台仅在完成登录、绑定、授权状态校验和安全审计所必需的范围内保存上述信息，不会额外收集与登录无关的第三方账号资料。

### 3. 双因素认证信息
当用户启用 2FA 时，平台可能保存 2FA 的启用状态、验证密钥、恢复相关配置和必要的认证日志，用于二次验证和账号安全保护。

平台不主动保存用户每次登录输入的动态验证码本身。用户应妥善保管 2FA 设备、恢复码及相关验证信息；如因用户保管不当导致账号风险，平台将依法并根据实际情况提供协助。

### 4. 调用元数据信息
为了计费、审计、故障排查、风控和服务统计，平台会保存与 API 调用有关的必要元数据，通常包括：
- 调用时间，精确到秒；
- API Key 及其对应用户；
- 调用所使用的模型；
- 调用渠道或路由信息；
- 费用信息；
- 订阅抵扣信息；
- 必要的错误码、响应状态、限流和风控记录。

平台不保存请求正文，但会保留上述元数据，以便核算费用、核对调用记录、提供客服支持、处理争议和履行法定义务。

### 5. 支付订单信息
平台通过 E 支付处理订单、充值、套餐购买、退款核验及账务结算。平台可能收集或保存的支付订单信息包括：
- 订单号；
- 订单金额；
- 支付状态；
- 支付时间；
- 商品或套餐信息；
- 退款申请与处理结果；
- 与订单核验直接相关的必要记录。

平台不保存用户支付账户的全部敏感信息；相关支付过程通常由 E 支付及其关联服务按照自身规则处理。用户应同时阅读其对应的隐私政策和服务说明。

### 6. 客服与投诉信息
当用户通过客服渠道咨询、申诉、报障、投诉或申请权利时，平台可能收集用户主动提供的联系方式、问题描述、工单信息、账号信息、截图、录音、聊天记录及与处理相关的必要证据材料。

上述信息仅用于答复咨询、处理故障、核实身份、解决纠纷、执行退款或其他合理的客户支持目的。

### 7. Bark 推送配置
当用户使用 Bark 等推送服务时，平台会处理用户自行填写的推送配置，例如设备标识、推送地址、推送密钥或标签等必要参数。

该等信息仅用于消息推送、通知触达和推送故障排查，用户可以在账户设置中修改或删除相关配置。

## 四、信息使用目的
平台处理上述信息的目的包括但不限于：
1. 提供账号注册、登录、绑定、授权和身份验证服务；
2. 维护 API 调用、路由转发、计费、订阅和结算功能；
3. 进行安全审计、风控识别、异常检测和攻击防护；
4. 处理客服咨询、投诉、退款、争议解决和售后支持；
5. 配置和发送 Bark 等通知服务；
6. 履行法律法规、监管要求或司法机关的合法要求；
7. 进行必要的产品优化、运营分析和服务改进。

## 五、信息共享、委托处理与第三方服务
### 1. 平台与第三方的关系
平台在实现服务过程中，可能与 GitHub、Telegram、E 支付、Bark 以及境内外模型服务商发生必要的数据交互。上述第三方均可能依据其自身隐私政策和服务条款独立处理相关信息。

平台仅在实现服务所必需的范围内向相关第三方传递必要信息。用户使用第三方登录、支付、推送或上游模型服务时，应理解相关第三方可能会独立收集、保存、使用或共享其服务所需的信息。

### 2. 请求转发与境内外上游
用户发起的请求会按照所选路由转发至境内或境外上游模型服务商。平台仅负责转发和基础服务支持，不对上游是否保存、审查、分析、训练或改进服务作出承诺，也无法控制其依照自身政策进行的处理。

### 3. 信息共享的情形
平台不会向无关第三方出售、出租用户个人信息。仅在以下情形下，平台可能共享必要信息：
- 已获得用户的同意或授权；
- 为完成用户明确发起的服务、支付、登录、推送或客服处理；
- 为履行法定义务、响应司法或行政要求；
- 为维护平台、用户或公共利益，处理安全事件、欺诈、滥用、侵权或其他违法违规行为；
- 涉及合并、收购、资产转让或其他业务重组，且接收方继续受本政策约束。

## 六、信息保存期限与删除规则
### 1. 请求正文
平台不保存请求正文。请求正文仅在转发和完成调用过程中短暂存在于必要的技术链路中，平台不以持久化方式留存。

### 2. 调用元数据、OAuth 记录、2FA 配置、安全日志
上述信息会在实现服务、账务核对、安全审计、争议处理和法定义务所需的期限内保存。达到保存目的后，平台将依法删除或匿名化处理；如法律法规另有要求，则按照法定期限继续保存。

### 3. 支付订单与客服记录
支付订单、退款记录、客服工单及投诉处理材料会在完成结算、风控、售后、争议解决和法定留存要求所需的期限内保存。期满后将依法删除、匿名化或作其他必要处理。

### 4. 账号注销与服务终止
用户注销账号或终止服务后，平台将在法律法规允许范围内，对不再需要的信息进行删除或匿名化处理；对因合规、审计、财务、争议处理或法定义务需要留存的信息，将按要求保留。

## 七、信息安全保护
平台采取符合行业通行标准的安全措施保护用户信息，包括但不限于：
- 访问控制与最小权限管理；
- 传输与存储加密；
- 敏感信息脱敏或分级处理；
- 安全审计与异常告警；
- 账号风控与操作留痕；
- 安全事件响应与处置机制。

用户应妥善保管账号密码、API Key、第三方登录凭证、2FA 设备和恢复信息，以及 Bark 或其他推送配置。因用户自行泄露、共享或不当保管造成的损失，平台将依法并结合实际情况处理。

1. 查询、复制本人在平台留存的个人信息；
2. 更正或补充不准确、不完整的信息；
3. 删除不再需要的信息；
4. 注销账号；
5. 撤回已授权的同意或授权，但不影响撤回前基于同意已进行的处理；
6. 获取个人信息处理规则的说明；
7. 对个人信息处理行为提出投诉、举报或申诉；
8. 就账号安全、异常登录、授权状态及相关风险申请协助。

用户提出上述请求时，平台可能要求进行必要的身份核验，以防止信息泄露或被冒用。对于法律法规要求留存的信息，平台将依法在可行范围内说明原因并处理。
