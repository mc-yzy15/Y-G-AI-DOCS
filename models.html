模型列表与选择

平台聚合多个生态的模型，通过统一的 API Key 调用。本页说明模型 ID 的获取方式与选型思路。

如何查看可用模型

可用模型及其 ID、价格、分组限制，以官网 模型广场 实时数据为准。模型上下架由平台统一维护，无需在客户端配置。

模型 ID 直接填写在请求的 model 字段中。ID 以控制台展示为准，文档中的示例 ID（如 gpt-4o、claude-sonnet-4-20250514、gemini-2.5-flash）为通用写法。

请求中指定模型

curl
curl https://ai.yzy15.dpdns.org/v1/chat/completions \
  -H "Authorization: Bearer sk-YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model": "YOUR_MODEL_ID",
       "messages": [{"role": "user", "content": "你好"}]}'

将 YOUR_MODEL_ID 替换为控制台「模型广场」提供的实际模型 ID。

模型暂不可用怎么办

  • 确认模型 ID 拼写与「模型广场」一致。
  • 确认账号所属分组允许使用该模型（403 时常见）。
  • 部分模型可能因供应商侧问题临时下架，可在官网公告或状态页查看。
  • 换用同生态的近似模型，或通过「模型广场」查看替代项。
模型价格与计费规则可能调整，请以官网「模型广场」与「计费与用量」页面公布的最新信息为准。
