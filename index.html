欢迎使用瀛光 AI API

瀛光 AI 是一个统一 AI 模型 API 网关：使用一套 API Key 和一套调用方式，即可接入主流大模型生态，兼容 OpenAI、Anthropic、Gemini 三大协议。

核心能力

一套 Key，全部模型

在控制台创建 API Key 后，即可通过同一鉴权方式调用平台提供的所有模型，无需为不同供应商单独申请密钥。

多协议兼容

同时提供 OpenAI Chat/Responses、Anthropic Messages、Gemini 三种协议入口，已有代码几乎零改动即可接入。

流式与标准模式

支持 SSE 流式输出与标准一次性响应，适合聊天机器人、Agent、工作流等各类场景。

用量透明

计费按 token 用量精确核算，控制台可随时查看余额与调用明细，详见「计费与用量」。

5 分钟快速接入

  1. 访问官网 ai.yzy15.dpdns.org 并完成注册。
  2. 在「令牌」页面创建你的 API Key（sk- 开头）。
  3. 选择合适的模型 ID（见「模型列表与选择」）。
  4. 将 API 地址与 Key 填入你的代码或客户端工具。
  5. 发送第一个请求，开始使用。
