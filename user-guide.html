平台用户手册

面向平台使用者的操作指南：注册、令牌管理、控制台常用功能与注意事项。

账号注册与登录

  1. 访问官网 ai.yzy15.dpdns.org。
  2. 点击「注册」，填写邮箱与密码完成注册。
  3. 登录后进入控制台首页，可见「额度」余额与快捷入口。

令牌（API Key）管理

控制台「令牌」页面用于创建和管理 API Key：

  • 创建令牌：填写名称后生成 sk- 开头的 Key，创建后仅完整显示一次。
  • 启用 / 禁用：可随时停用某个 Key，停用后请求立即失效。
  • 额度限制：可为令牌设置可用额度上限，防止 Key 被盗用时超量消耗。
  • 删除：删除后不可恢复。
创建多个令牌并分配不同用途（开发 / 生产 / 团队），便于审计与隔离风险。

控制台常用功能

模型广场

浏览可用模型、价格与规格，查看模型 ID。

充值

为账号充值或兑换额度，查看充值记录。

日志

查看请求记录、token 消耗与响应状态，便于排障与对账。

设置

修改密码、绑定安全信息，管理账号资料。

订阅与额度说明

  • 平台按「额度」计费，500,000 quota = $1。
  • 不同分组 / 套餐享受不同的分组倍率，具体见「计费与用量」。
  • 额度余额不足时调用会返回 403，补充额度后自动恢复。

使用规范提醒

  • 禁止将账号、令牌分享给未授权第三方，避免资损。
  • 请遵守《用户协议》与《隐私政策》，合法合规使用平台服务。
  • 如发现异常扣费或令牌被盗用，请立即在控制台禁用相关令牌并联系客服。
