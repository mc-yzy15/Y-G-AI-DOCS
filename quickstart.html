快速开始

以下流程用于先完成最短路径接入，再按当前部署补齐协议细节。

所有字段、路径、认证方式和模型列表以实际部署、当前控制台或最新官方文档为准。

六步快速开始

  1. 确认你要接入的协议入口：OpenAI Chat Completions、OpenAI Responses、Anthropic Messages / Claude、Gemini API。
  2. 从当前部署的控制台或文档获取 API Key，勿在浏览器页面粘贴真实密钥。
  3. 在当前实例中选择一个可用模型，并记录实际返回或支持的 MODEL_ID。
  4. 选择主用或备用 BASE_URL，以实际部署可用性为准；不要预设固定 endpoint。
  5. 复制当前协议示例，并用安全占位符替换 API_KEY、MODEL_ID、BASE_URL、AUTH_HEADER。
  6. 发送请求后核对响应结构、错误信息、流式行为和字段名是否与当前部署一致。

主备地址

  • 主用地址：https://ai.yzy15.dpdns.org
  • 备用地址：https://aio.yzy15.dpdns.org

占位符约定

  • API_KEY：仅在服务端环境保存和注入。
  • MODEL_ID：以当前部署实际可用模型标注为准。
  • BASE_URL：在主备地址之间选择当前可用基址。
  • AUTH_HEADER：以当前部署确认的认证头名称为准。

示意请求骨架

协议形态参考

下面的请求只展示协议形状，不承诺固定路径、固定头名或固定字段集合。

BASE_URL=<deployment base URL>
API_KEY=<your API key>
MODEL_ID=<model available in this deployment>
AUTH_HEADER=<header confirmed by deployment documentation>

curl "$BASE_URL/<deployment path>" \
  -H "$AUTH_HEADER: $API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "'"$MODEL_ID"'",
    "messages": [
      {"role": "user", "content": "Hello"}
    ]
  }'
