快速开始

从注册账号到发出第一个请求，大约需要 5 分钟。

1. 注册并创建 API Key

访问 ai.yzy15.dpdns.org 注册账号。登录后进入「令牌」页面，点击创建令牌，得到以 sk- 开头的 API Key。

API Key 只在创建时完整显示一次，请立即复制并妥善保管。不要分享给他人或提交到代码仓库。

2. 确定 API 地址与模型

OpenAI 兼容调用地址为 https://ai.yzy15.dpdns.org/v1/chat/completions。模型 ID 请以控制台「模型广场」实际提供的为准，常用写法如 gpt-4o、claude-sonnet-4-20250514、gemini-2.5-flash。

3. 发送第一个请求

curl
curl https://ai.yzy15.dpdns.org/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-YOUR_API_KEY" \
  -d '{
    "model": "gpt-4o",
    "messages": [
      {"role": "user", "content": "你好，请用一句话介绍你自己"}
    ]
  }'

4. Python 示例

Python + requests
import requests

resp = requests.post(
    "https://ai.yzy15.dpdns.org/v1/chat/completions",
    headers={
        "Authorization": "Bearer sk-YOUR_API_KEY",
        "Content-Type": "application/json",
    },
    json={
        "model": "gpt-4o",
        "messages": [{"role": "user", "content": "你好"}],
    },
    timeout=60,
)
print(resp.json()["choices"][0]["message"]["content"])

5. 使用 OpenAI SDK

Python + openai
from openai import OpenAI

client = OpenAI(
    api_key="sk-YOUR_API_KEY",
    base_url="https://ai.yzy15.dpdns.org/v1",
)

resp = client.chat.completions.create(
    model="gpt-4o",
    messages=[{"role": "user", "content": "你好"}],
)
print(resp.choices[0].message.content)
请求成功后，你会收到类似 OpenAI 标准格式的 JSON 响应。若遇到 401，请检查 Key 是否正确；若遇到 404，请确认模型 ID 与路径是否正确。
