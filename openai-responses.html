Responses

OpenAI 新一代 Responses 接口，将对话、工具调用统一为「输入 → Response」模型。与 Chat Completions 相比，请求与响应结构更简洁。

Responses 接口为 OpenAI 兼容扩展。是否对所有模型可用取决于模型本身支持情况，接入前建议先测试目标模型。

接口信息

请求方式POST
请求路径https://ai.yzy15.dpdns.org/v1/responses
鉴权Authorization: Bearer sk-...
Content-Typeapplication/json

请求示例

curl
curl https://ai.yzy15.dpdns.org/v1/responses \
  -H "Authorization: Bearer sk-YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-4o",
    "input": "你好，请介绍一下你自己",
    "max_output_tokens": 1024
  }'

核心请求字段

字段类型说明
modelstring必填，模型 ID。
inputstring / array用户输入，可为字符串或消息数组（含 role、content）。
instructionsstring可选，系统指令，相当于 system prompt。
max_output_tokensinteger可选，最大输出 token 数。
temperaturenumber可选，采样温度。
toolsarray可选，工具定义列表。

响应结构

JSON 响应示例
{
  "id": "resp_xxx",
  "object": "response",
  "model": "gpt-4o",
  "output": [
    {
      "type": "message",
      "role": "assistant",
      "content": [
        {"type": "output_text", "text": "你好！我是……"}
      ]
    }
  ],
  "usage": {
    "input_tokens": 24,
    "output_tokens": 88,
    "total_tokens": 112
  }
}

与 Chat Completions 的差异

维度Chat CompletionsResponses
路径/v1/chat/completions/v1/responses
输入字段messagesinput（字符串或数组）
输出结构choices[].message.contentoutput[] 消息块
token 统计prompt/completion/total_tokensinput/output/total_tokens

SDK 调用

Python + openai
from openai import OpenAI

client = OpenAI(
    api_key="sk-YOUR_API_KEY",
    base_url="https://ai.yzy15.dpdns.org/v1",
)

resp = client.responses.create(
    model="gpt-4o",
    input="用一句话解释什么是 API",
)
print(resp.output_text)
不同模型对 Responses 的兼容程度不同。若目标模型返回 400「unsupported」等错误，可改用 Chat Completions 调用同一模型。
