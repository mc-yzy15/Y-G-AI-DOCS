Messages / Claude

Anthropic 兼容的 Messages 接口，使用原生 Claude 请求格式接入 Claude 系列模型。

接口信息

请求方式POST
请求路径https://ai.yzy15.dpdns.org/v1/messages
鉴权x-api-key: sk-...（部分客户端亦接受 Bearer）
版本头anthropic-version: 2023-06-01
Content-Typeapplication/json

请求示例

curl
curl https://ai.yzy15.dpdns.org/v1/messages \
  -H "x-api-key: sk-YOUR_API_KEY" \
  -H "anthropic-version: 2023-06-01" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "claude-sonnet-4-20250514",
    "max_tokens": 1024,
    "system": "你是一位严谨的助手。",
    "messages": [
      {"role": "user", "content": "请解释什么是 API 网关"}
    ]
  }'

核心请求字段

字段类型说明
modelstring必填，Claude 模型 ID。
max_tokensinteger必填，最大输出 token 数。
messagesarray必填，对话消息，支持 user / assistant 角色。
systemstring可选，系统提示词。
temperaturenumber可选，采样温度。
top_pnumber可选，核采样。
streamboolean可选，SSE 流式输出。

响应结构

JSON 响应示例
{
  "id": "msg_xxx",
  "type": "message",
  "role": "assistant",
  "model": "claude-sonnet-4-20250514",
  "content": [
    {
      "type": "text",
      "text": "API 网关是……"
    }
  ],
  "stop_reason": "end_turn",
  "usage": {
    "input_tokens": 58,
    "output_tokens": 96
  }
}

流式输出

设置 "stream": true 后按 Anthropic SSE 格式返回，事件类型包括 message_start、content_block_delta、message_stop 等。文本增量位于 delta.text。

SSE 输出示例
event: message_start
data: {"type":"message_start","message":{"id":"msg_xxx"}}

event: content_block_delta
data: {"type":"content_block_delta","delta":{"type":"text_delta","text":"API 网关是"}}

event: content_block_delta
data: {"type":"content_block_delta","delta":{"type":"text_delta","text":"一个统一入口。"}}

event: message_stop
data: {"type":"message_stop"}

使用 Anthropic SDK

Python + anthropic
from anthropic import Anthropic

client = Anthropic(
    api_key="sk-YOUR_API_KEY",
    base_url="https://ai.yzy15.dpdns.org",
)

resp = client.messages.create(
    model="claude-sonnet-4-20250514",
    max_tokens=1024,
    messages=[{"role": "user", "content": "你好"}],
)
print(resp.content[0].text)
Claude 模型 ID 以控制台实际提供为准。部分客户端要求 anthropic-dangerous-direct-browser-access 头，若未配置可能被浏览器策略拦截。

如需以 OpenAI 格式调用 Claude 模型，可使用 Chat Completions 接口并填写对应模型 ID。
