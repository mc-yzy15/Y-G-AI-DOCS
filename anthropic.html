Anthropic Messages / Claude

本页只说明 Anthropic Messages / Claude 协议的最小可用形态，便于你在当前部署里确认请求、读响应和判断流式边界。

以下示例均使用占位符。不要把本页字段直接套用到 OpenAI Chat Completions、OpenAI Responses 或 Gemini API。

协议目的

适合消息式对话、系统提示与流式文本输出。若你的部署启用了兼容层，这一页只帮助你确认 Anthropic Messages / Claude 的语义，不承诺与原生 Anthropic 实现逐项同构。

最小概念请求

  • 只保留一个模型标识、一个最小消息数组和必要认证头。
  • 请求路径由部署决定，示例中的路径占位符不能当作固定 endpoint。
  • 不要混入 OpenAI 或 Gemini 的专属字段。

响应阅读

  • 优先读取文本内容、停止原因、错误对象和 HTTP 状态码。
  • 如果返回流式片段，先确认事件块是否仍然对应同一请求上下文。
  • 遇到异常时，以部署返回的错误结构为准，不依赖固定字段名。

流式 / 错误边界

  • 是否支持流式、如何结束、是否提供增量文本，全部以当前部署为准。
  • 403、429、5xx 与内容层错误要分开处理。
  • 本页不提供管理接口，也不假定有后台配置路径。
部署依赖提示：请先确认当前部署的 Base URL、认证头名称、可用模型与路径；若平台切换兼容层实现，示例中的消息结构可能需要同步调整。

cURL

BASE_URL=<deployment base URL>
API_KEY=<your API key>
MODEL_ID=<model available in this deployment>
AUTH_HEADER=<header confirmed by deployment documentation>
ENDPOINT_PATH=<deployment path>

curl "$BASE_URL/$ENDPOINT_PATH" \
  -H "$AUTH_HEADER: $API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "'"$MODEL_ID"'",
    "messages": [
      {"role": "user", "content": "Hello"}
    ]
  }'

Python requests

import requests

BASE_URL = "<deployment base URL>"
API_KEY = "<your API key>"
MODEL_ID = "<model available in this deployment>"
AUTH_HEADER = "<header confirmed by deployment documentation>"
ENDPOINT_PATH = "<deployment path>"

response = requests.post(
    f"{BASE_URL}/{ENDPOINT_PATH}",
    headers={AUTH_HEADER: API_KEY, "Content-Type": "application/json"},
    json={"model": MODEL_ID, "messages": [{"role": "user", "content": "Hello"}]},
    timeout=30,
)
print(response.status_code)
print(response.text)

JavaScript fetch

const BASE_URL = '<deployment base URL>';
const API_KEY = '<your API key>';
const MODEL_ID = '<model available in this deployment>';
const AUTH_HEADER = '<header confirmed by deployment documentation>';
const ENDPOINT_PATH = '<deployment path>';

const response = await fetch(`${BASE_URL}/${ENDPOINT_PATH}`, {
  method: 'POST',
  headers: {
    [AUTH_HEADER]: API_KEY,
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({
    model: MODEL_ID,
    messages: [{ role: 'user', content: 'Hello' }],
  }),
});

console.log(await response.text());

PHP cURL

<?php
$baseUrl = '<deployment base URL>';
$apiKey = '<your API key>';
$modelId = '<model available in this deployment>';
$authHeader = '<header confirmed by deployment documentation>';
$endpointPath = '<deployment path>';

$ch = curl_init($baseUrl . '/' . $endpointPath);
curl_setopt_array($ch, [
  CURLOPT_POST => true,
  CURLOPT_HTTPHEADER => [$authHeader . ': ' . $apiKey, 'Content-Type: application/json'],
  CURLOPT_POSTFIELDS => json_encode([
    'model' => $modelId,
    'messages' => [[ 'role' => 'user', 'content' => 'Hello' ]],
  ]),
  CURLOPT_RETURNTRANSFER => true,
]);
echo curl_exec($ch);
