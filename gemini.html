Gemini API

以 Google Gemini 原生格式调用平台提供的 Gemini 系列模型。

接口信息

请求方式POST
请求路径https://ai.yzy15.dpdns.org/v1beta/models/{model}:generateContent
鉴权?key=sk-... 或 x-goog-api-key 头
Content-Typeapplication/json
Gemini 模型通常也可以通过 OpenAI 兼容的 Chat Completions 接口调用。两种方式请任选其一，具体模型 ID 以控制台为准。

请求示例

curl
curl "https://ai.yzy15.dpdns.org/v1beta/models/gemini-2.5-flash:generateContent?key=sk-YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "systemInstruction": {
      "parts": [{"text": "你是瀛光 AI 助手。"}]
    },
    "contents": [
      {
        "role": "user",
        "parts": [{"text": "请用一句话介绍 Gemini"}]
      }
    ],
    "generationConfig": {
      "temperature": 0.7,
      "maxOutputTokens": 1024
    }
  }'

核心请求字段

字段类型说明
contentsarray必填，对话内容，元素含 role 与 parts。
contents[].partsarray输入片段，文本用 {"text": "..."}。
systemInstructionobject可选，系统指令。
generationConfigobject可选，含 temperature、maxOutputTokens、topP 等。

响应结构

JSON 响应示例
{
  "candidates": [
    {
      "content": {
        "role": "model",
        "parts": [{"text": "Gemini 是 Google 的多模态大模型。"}]
      },
      "finishReason": "STOP"
    }
  ],
  "usageMetadata": {
    "promptTokenCount": 18,
    "candidatesTokenCount": 22,
    "totalTokenCount": 40
  }
}

使用 Google SDK

Python + google-genai
from google import genai

client = genai.Client(
    api_key="sk-YOUR_API_KEY",
    http_options={"base_url": "https://ai.yzy15.dpdns.org"},
)

resp = client.models.generate_content(
    model="gemini-2.5-flash",
    contents="你好，请自我介绍一下",
)
print(resp.text)
部分 Google SDK 会校验模型名是否以 models/ 前缀开头，若报错请在模型 ID 前补全为 models/gemini-2.5-flash 形式。

若希望用统一 OpenAI 格式调用 Gemini 模型，请阅读 Chat Completions。
