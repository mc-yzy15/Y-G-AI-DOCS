常见问题

如果这里没有你要的答案，请回到当前实例文档查看部署差异。

Key 暴露了怎么办？

立即停止使用、轮换密钥，并检查日志、仓库、截图和前端页面中是否遗留凭据。

认证失败或路径不匹配？

核对当前部署确认的 AUTH_HEADER、Base URL 和 API path，优先查看当前实例文档。

模型不存在或不可用？

模型名由实际部署决定。请查看当前实例提供的模型列表，不要依赖旧示例。

主站不可用，何时切换备用地址？

只有在主站不可用或部署方明确提示时切换到 https://aio.yzy15.dpdns.org。

超时、流式异常或字段不兼容？

这些问题通常由部署差异、网络或兼容层实现引起，请以当前实例文档和错误信息为准。

如何报告问题？

保留请求时间、协议页、模型名、错误信息和脱敏后的响应片段，再联系支持渠道。

如需更具体的排查步骤，请回到当前实例文档核对协议页与路径。
