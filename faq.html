常见问题

按主题整理了接入与使用中的高频问题。若未覆盖你的问题，可在官网提交工单或联系客服。

接入与鉴权

返回 401 Unauthorized 怎么办？

说明 API Key 缺失或无效。请确认：Key 是否完整复制（以 sk- 开头）、是否已在控制台禁用或删除、Header 是否写为 Authorization: Bearer sk-...。

返回 404 Not Found？

请检查请求路径与模型 ID。常见原因：路径写错（应为 /v1/chat/completions）、模型 ID 不在「模型广场」列表中、或该模型当前不可用。

Base URL 应该填什么？

主地址 https://ai.yzy15.dpdns.org，备用 https://aio.yzy15.dpdns.org。多数 SDK 的 base_url 需以 /v1 结尾，请按客户端要求填写。

模型与协议

支持哪些协议？

支持 OpenAI Chat Completions 与 Responses、Anthropic Messages、Gemini 原生接口，详见各协议文档。

模型 ID 在哪里查？

以官网「模型广场」实时展示的模型 ID 为准，请求时填入 model 字段。

Claude 模型能用 OpenAI 格式调用吗？

可以。在 Chat Completions 的 model 字段填入 Claude 模型 ID 即可，平台会完成协议转换。

计费与账户

余额怎么扣的？

按 token 用量核算，公式见「计费与用量」页。响应中 usage 字段会给出本次消耗。

为什么请求失败了还扣费？

通常只有在模型开始生成并返回内容后才会计费；连接中断前的已生成 token 仍可能按量计入。若认为计费异常，可在控制台「日志」中核对并联系客服。

怎么充值？

登录官网控制台进入「充值」页面，按提示选择充值方式与金额。

连接与性能

主地址连不上怎么办？

可将 Base URL 切换为备用地址 https://aio.yzy15.dpdns.org 或 CN2 专线 https://aicn.yzy15.dpdns.org，或访问状态页查看服务状态。

请求很慢？

可尝试：改用 stream: true 流式接收、选择低延迟模型、减少历史消息携带量、确认本地网络到服务端延迟。

返回 429 Too Many Requests？

触发了频率或并发限制。请降低调用频率，或联系管理员调整当前分组的速率限制。
