面向企业交付的 AI 平台说明。

瀛光 AI 由北京仙盛科技有限公司运营，定位为面向企业客户的 AI 平台与统一 API 网关，覆盖模型接入、协议兼容、调用路由、权限与用量管理、账单与监控等能力，并支持向本地化算力环境延展。

01

平台定位与服务范围

保持 B 端表达，聚焦能力边界，不编造未经验证的企业信息。

  • 企业级 AI 基础设施：为企业内部应用、业务系统与开发团队提供统一接入层，帮助模型能力进入可管理、可审计、可持续运维的生产环境。
  • 平台服务范围：覆盖兼容式 API 接入、多模型路由、权限边界、使用量统计、账单协同、运行监控与基础运维支持。
  • 技术团队能力：以平台工程、接口兼容、部署交付、运行保障与持续迭代为导向开展工作；本页不披露未经确认的人数、履历、客户或资质信息。
本页面只保留公开介绍所需的能力边界，不扩展到首页式的仪表盘骨架、浮层网格或双栏 Hero 卡片。
02

本地部署与能力方向

面向需要数据边界、算力控制与内网可用性的部署场景。

H200 本地部署方向
GB300 / A180G 本地部署方向
  • 支持围绕 H200、GB300、A180G 等本地部署硬件方向进行方案规划，适合对算力部署与数据驻留有要求的组织。
  • 公开展示约 200 峰值并发、约 150 token/s 峰值生成速度，作为系统能力参考口径，具体结果受模型、上下文、任务类型与网络环境影响。
  • 可见性能口径：本页中的峰值并发与生成速度仅作为公开展示参考，不等同于所有模型、所有上下文、所有网络环境下的实际性能。
保留真实内容的同时，仅以文字和分隔线组织信息流，不引入首页视觉中的仪表盘与卡片堆叠。
03

服务状态

仅保留 OpenAI、Anthropic、瀛光 AI 三个入口，并保留可独立打开的状态逻辑。

OpenAI
自动详情暂不可读取
  • 数据来源：官方状态页
  • 读取逻辑：保留官方状态页，不猜测 JSON endpoint
  • 展示原则：自动详情暂不可读取时不做额外推断
Anthropic
自动详情暂不可读取
  • 数据来源：官方状态页
  • 读取逻辑：读取 https://status.claude.com/api/v2/status.json 的 payload.page.status.indicator / payload.page.status.description
  • 展示原则：仅在字段明确时展示状态，否则保留中性提示
瀛光 AI
主状态页与备用状态页待自动读取
  • 数据来源：主状态页
  • 备用地址：备用状态页
  • 读取逻辑：主状态页失败后仅尝试备用地址；成功后明确显示当前使用主站或备用站，失败则标记不可用
状态读取保留主备降级与 AbortController 超时控制；页面主体在任一状态读取失败时仍应保持完整可见。
